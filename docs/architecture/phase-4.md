# Phase 4 — Marketplace

## Delivered

- Homepage CMS (`CmsPage` slug `home`) + Admin editor at `/admin/cms`
- Shop search/filters/sort: q, animal, category, store, price bands, onSale, pagination
- Category tree + `/categories/[...slug]` → shop filter
- Store directory + storefront SEO metadata
- PDP SEO (`generateMetadata`) + add-to-cart client
- `/deals` `/new` `/best-sellers` convenience routes
- `sitemap.xml` + `robots.txt`
- Seed: 50+ published products + homepage CMS
